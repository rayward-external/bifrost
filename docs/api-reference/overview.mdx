Browse the complete Bifrost REST API using the navigation on the left.

The API is grouped into the following sections:

- **Chat Completions** — OpenAI-compatible chat and text generation
- **Models** — list and inspect available models
- **Governance** — virtual keys, model limits, budgets
- **Management** — configuration, logging, cache, and health

All endpoints accept and return JSON. Authentication is via the `x-api-key` header (virtual key or admin key depending on the endpoint).
